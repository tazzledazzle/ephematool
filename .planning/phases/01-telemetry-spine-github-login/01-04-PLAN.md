## Phase Goal

**As an** SRE, **I want to** sign in with GitHub to a running dashboard and find the platform's own traces, metrics, and logs in Grafana, **so that** the platform is observable from the moment it exists.

<objective>
Deliver the server side of "SRE can log in with GitHub" (AUTH-01): GitHub OAuth App login with `read:org` (D-15), state + PKCE, a fail-closed org/team allowlist from config (D-01), admin-by-username with a viewer default (D-02), a denied flow with a log event (D-04), Redis-backed sessions with a 7-day idle timeout and a 30-day absolute lifetime (D-03, D-14), sign-out, and the first real Postgres read and write (`users`). This plan also builds the Wave 0 fake GitHub (VALIDATION) so a fresh checkout and CI can exercise login without real credentials.

Sliding renewal (the 5-minute touch) and the session-expiry tests are delivered in plan 01-07 as part of the "stay signed in" slice. This plan configures IdleTimeout, Lifetime, and Persist; 01-07 makes activity extend the session.

Output: the fake GitHub (library + binary + Compose overlay), internal/auth, internal/store (pgx + otelpgx + goose + sqlc), wiring into the API, and a regenerated OpenAPI spec.
</objective>
