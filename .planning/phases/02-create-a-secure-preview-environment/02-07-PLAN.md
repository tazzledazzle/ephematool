## Phase Goal

**As an** SRE, **I want to** create a preview environment from a branch, PR or ref with one dashboard action, **so that** it comes up isolated, resource-limited and emitting telemetry, with the whole creation visible as one trace.

<objective>
Create the approved-template catalog (D-10, D-12): the `web-app` Helm chart with a JSON Schema, a shared `sizes.yaml` for S/M/L (UI-SPEC values, user-confirmed), Go loading via go:embed, schema validation with field errors (ENV-02) and the form-schema trimmer the UI renders. The chart injects OTEL settings for OBS-03 and routes the exempt health path (D-05).

Dependencies: `github.com/santhosh-tekuri/jsonschema/v6` v6.0.3 (approved in 02-01, same engine Helm 4.3.0 uses); `golang.org/x/text` and `gopkg.in/yaml.v3` promoted from indirect to direct.
Output: templates/ package and chart, internal/catalog with table tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User-supplied template values → Helm install | Values flow into rendered manifests on the runner |
| Chart authors → cluster | A chart could try to weaken guardrails |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-07-01 | Tampering | Free-form values override image or platform settings | mitigate | x-platform keys rejected server-side; provision.sh passes platform keys with --set after -f so they win; additionalProperties false |
| T-02-07-02 | Elevation of privilege | Template omits guardrails or auth | mitigate | Auth is a Traefik entrypoint chain, quota/netpol come from the platform baseline (plan 02-13), not the chart |
| T-02-07-03 | Elevation of privilege | Pod gets API credentials | mitigate | automountServiceAccountToken false, non-root, drop ALL, seccomp RuntimeDefault |
| T-02-07-04 | Denial of service | Excessive replicas/resources | mitigate | Schema caps replicas at 3; presets only, no raw CPU/memory input (GRD-01) |
| T-02-SC | Tampering | go get jsonschema/v6 | mitigate | Approved in 02-01, exact pin, same version as Helm 4.3.0 |
