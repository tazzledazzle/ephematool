</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → audit API | Any signed-in user can call it |
| URL search params → interstitial | env and return are attacker-controlled links |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-16-01 | Information disclosure | Non-admin reads audit | mitigate | RequireRole admin resolved per request; 403 tests incl. demotion |
| T-02-16-02 | Spoofing | Open redirect via return param | mitigate | SPA only navigates to the mint response URL; server validates return host; e2e evil.example case |
| T-02-16-03 | Information disclosure | Env enumeration via interstitial | mitigate | One denied message for unknown and forbidden |
| T-02-16-04 | Information disclosure | Session cookie sent to preview | mitigate | Host-only session cookie; e2e asserts no ephematool_session on preview requests |
| T-02-16-05 | Tampering | XSS via search params | mitigate | Text rendering only; never used as href |
| T-02-16-06 | Repudiation | Audit tampering through UI | mitigate | Read-only API; no mutation endpoints exist |
</threat_model>
