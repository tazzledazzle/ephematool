## Phase Goal

**As an** SRE, **I want to** create a preview environment from a branch, PR or ref with one dashboard action, **so that** it comes up isolated, resource-limited and emitting telemetry, with the whole creation visible as one trace.

<objective>
The worker half of ENV-01 and OBS-02 (RESEARCH Patterns 8 and 9): asynq handlers `env:dispatch`, `env:poll`, `env:probe`, `env:sweep` implementing the forward-only state machine requested -> provisioning -> running | failed with CAS updates; serial dispatch with spacing; synthetic Actions spans; worker wiring with the app-role DB and GitHub App; and `env-trace.sh` proving one trace in Tempo on the fake stack.

What the trace can and cannot show is stated in code comments and the README (plan 02-17): run/job/step durations at 1s resolution, appended when the run completes; no step internals.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Worker → GitHub Actions | Non-idempotent dispatch POST; rate limits |
| Worker → preview gateway | Probe reaches untrusted preview code |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-11-01 | Tampering | Duplicate dispatch after ambiguous result | mitigate | ClaimDispatch CAS; correlation search before any retry; never re-POST |
| T-02-11-02 | Denial of service | GitHub secondary rate limits / ban | mitigate | Serial dispatch server, spacing, RetryAfter, ETag polling with backoff and jitter |
| T-02-11-03 | Information disclosure | Credentials in probe | mitigate | Probe sends no cookies or tokens, only the exempt health path; redirects not followed |
| T-02-11-04 | Spoofing | Green workflow treated as running | mitigate | running only after a 2xx probe (D-18) |
| T-02-11-05 | Information disclosure | Workflow inputs or tokens on spans | mitigate | Spans carry run ids, conclusions, timings and env attributes only |
| T-02-11-06 | Denial of service | Lost tasks after restart | mitigate | Sweeper re-enqueues from DB with Unique; traceparent stored on the row |
</threat_model>
