## Phase Goal

**As an** SRE, **I want to** create a preview environment from a branch, PR or ref with one dashboard action, **so that** it comes up isolated, resource-limited and emitting telemetry, with the whole creation visible as one trace.

<objective>
Fill the reserved `*/environments` collector slot (OBS-03, RESEARCH Pattern 10): a separate HTTP-only receiver, lower memory limiter, OTTL filter dropping id-less and platform-spoofing data, resource stamping, bounded batches and separate exporter instances. Add the `cmd/sampleapp` reference workload (Wave 0) used by kind verification (plan 02-13), and a verify script that proves the filter end to end on the compose stack.

Honest scope (state in comments): collector-contrib has no rate limiter; protection is the body cap, bounded batches and queues, and the lower memory threshold. Resource attributes are client-asserted; Phase 6 stamps identity from namespace labels.
</objective>
