## Phase Goal

**As an** SRE, **I want to** create a preview environment from a branch, PR or ref with one dashboard action, **so that** it comes up isolated, resource-limited and emitting telemetry, with the whole creation visible as one trace.

<objective>
The create API slice: server-authoritative validation pipeline (D-06, D-07, D-11/D-23, D-10, D-12), environment record with a server-generated `pv-<10 chars>` id that becomes the namespace and the `<env-id>.preview.localhost` host, never branch-derived (D-03 naming, which still holds after D-20 replaced ingress-nginx), owner and informational expiry (D-08, D-13), audit on every outcome (D-19), enqueue of `env:dispatch`, plus read endpoints the dashboard needs. The worker that dispatches is plan 02-11.

Order (RESEARCH "Create handler order", refined for UX): (1) resolve role now -> 403 denied/not_creator; (2) allowlist exact, case-insensitive, fail closed when empty -> 422 denied/repo_not_allowed; (3) local checks collected together: ref format, template known and usable, size known, values schema -> 422 rejected; (4) resolve ref to SHA via the App -> 422 rejected ref_not_found|pr_not_eligible; (5) GHCR image check -> 422 rejected image_not_found; (6) one transaction: insert environment + audit success; (7) enqueue dispatch (failure is logged; the sweeper in 02-11 recovers); 202.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-10-01 | Elevation of privilege | Viewer or demoted creator creates | mitigate | Resolve role per request first; integration test for demotion between two creates |
| T-02-10-02 | Tampering | Input injection into workflow / shell | mitigate | Allowlist, ref regex, enums, schema validation, server-generated pv- id; workflow re-validates (02-13) |
| T-02-10-03 | Tampering | SSRF via repo/ref | mitigate | Repo must be in ALLOWED_REPOS before any GitHub call; ref regex first; no user URLs |
| T-02-10-04 | Repudiation | Unaudited denial or rejection | mitigate | Every path writes one audit row; tests count rows per outcome |
| T-02-10-05 | Elevation of privilege | Fork PR code | mitigate | pr_not_eligible from ghapp; tested with PR 2 and 3 |
| T-02-10-06 | Information disclosure | Values or tokens in logs/spans | mitigate | Logs carry ids and codes only; span attributes limited to env id, owner, template |
| T-02-10-07 | Denial of service | Unbounded list/limit | mitigate | limit 1..20; ref maxLength 200 |
