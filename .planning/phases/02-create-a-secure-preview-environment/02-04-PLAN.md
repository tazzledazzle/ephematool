## Phase Goal

**As an** SRE, **I want to** create a preview environment from a branch, PR or ref with one dashboard action, **so that** it comes up isolated, resource-limited and emitting telemetry, with the whole creation visible as one trace.

<objective>
Persist environments and an append-only audit log enforced by the database (D-19 as refined by D-24): a second login role `ephematool_app` for runtime with INSERT/SELECT on audit_events only, plus triggers that reject UPDATE/DELETE/TRUNCATE. Migrations move to goose's Provider API with a session locker (WR-11) and run as the owner. Provide `internal/audit` (record + cursor list) and a reusable two-role integration harness (Wave 0).

Output: migrations 00002/00003, sqlc queries and generated code, Provider-based Migrate, audit package, testenv harness, compose DB URLs, //:test_integration entries.
</objective>
