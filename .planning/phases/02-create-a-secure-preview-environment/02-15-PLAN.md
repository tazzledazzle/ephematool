## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → Traefik preview entrypoint | Untrusted hosts, cookies and paths |
| Traefik → API ForwardAuth | Decision endpoint over the compose network |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-15-01 | Elevation of privilege | Router without auth | mitigate | Entrypoint-level middleware, not per-router; one catch-all router |
| T-02-15-02 | Information disclosure | Session/preview cookie reaching upstream | mitigate | authResponseHeaders [Cookie]; preview-gate check 6 |
| T-02-15-03 | Spoofing | Ticket replay/forgery through the real gateway | mitigate | preview-gate checks 3 and 5 |
| T-02-15-04 | Information disclosure | Tickets in access logs or telemetry | mitigate | accesslog=false; redaction scans for ticket=, cookie names, PEM headers and a minted value |
| T-02-15-05 | Tampering | Clickjacking of the console (IN-04) | mitigate | X-Frame-Options DENY and CSP frame-ancestors 'none' |
| T-02-15-06 | Spoofing | Indexing of previews | mitigate | X-Robots-Tag noindex on every preview response |
| T-02-SC | Tampering | Traefik and whoami images | mitigate | Digest-pinned from versions.env (approved 02-01) |
</threat_model>
