<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Preview host (untrusted PR code, sibling previews) → ForwardAuth endpoint | Cookies and headers on preview requests are attacker-influenced |
| Dashboard origin → preview origin | Only a signed ticket crosses; the session cookie must not |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-08-01 | Spoofing | Ticket/cookie forgery, alg confusion | mitigate | HS256 pinned via WithValidMethods, 32+ byte key from file, kid lookup, issuer/audience/exp required; tests for none/RS256/HS512/unknown key |
| T-02-08-02 | Spoofing | Ticket replay | mitigate | 60s TTL and single-use jti via Redis SET NX EX 120; replay test |
| T-02-08-03 | Spoofing | Open redirect via return | mitigate | ret inside signed claims; SafeReturn requires the env's exact preview host and a clean single-slash path |
| T-02-08-04 | Information disclosure | Platform session reaching preview code | mitigate | Session cookie stays host-only (never Domain); preview cookie stripped through the Cookie response header; e2e asserts in plan 02-16 |
| T-02-08-05 | Tampering | Sibling-preview cookie tossing | mitigate | Iterate all same-named cookies, accept only a valid env-bound one, strip all |
| T-02-08-06 | Elevation of privilege | Health-path bypass | mitigate | Exact path match, GET/HEAD only, traversal and encoded-dot rejection |
| T-02-08-07 | Information disclosure | Environment enumeration via mint | mitigate | One 403 body for unknown and forbidden |
| T-02-08-08 | Denial of service | Missing key silently allowing | mitigate | Missing/short key -> 503 fail closed |
</threat_model>
