## Phase Goal

**As an** SRE, **I want to** create a preview environment from a branch, PR or ref with one dashboard action, **so that** it comes up isolated, resource-limited and emitting telemetry, with the whole creation visible as one trace.

<objective>
Build `internal/ghapp`, the platform GitHub App client (D-14, separate from the Phase 1 OAuth App): app JWT and installation token cache, creator-team membership at request time (D-06), ref/PR/SHA resolution with fork checks (Pitfalls 7, 8), anonymous GHCR manifest check (D-11 refined by D-23), workflow dispatch with run id and run-name correlation fallback (D-15), and ETag polling primitives (D-16). Tested against the fake GitHub from plan 02-03 with plain unit tests (no Docker).

Dependency: `github.com/golang-jwt/jwt/v5` v5.3.1, approved in plan 02-01.
Output: package ghapp with tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Platform → GitHub API / GHCR | Outbound calls with an App installation token; responses are untrusted |
| User input (repo, ref) → URL paths | Ref strings become API path segments |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-05-01 | Tampering | SSRF/path injection via ref or repo | mitigate | ValidateRefInput regexes before any HTTP; go-github builds and escapes paths; GHCR base URL from config only; zero-request test for invalid input |
| T-02-05-02 | Elevation of privilege | Fork PR code deployed into the cluster | mitigate | PR eligible only when head.repo == base.repo and state open; deleted forks rejected (Pitfall 8) |
| T-02-05-03 | Information disclosure | Installation token or private key leaked to logs/spans | mitigate | Token only inside the transport; PEM read once from file; no token attributes; redaction scan extended in plan 02-15 |
| T-02-05-04 | Spoofing | JWT algorithm confusion | mitigate | Explicit SigningMethodRS256 for the app JWT |
| T-02-05-05 | Tampering | Re-pushed image tag changes what runs | mitigate | Return digest-pinned `@sha256:` reference |
| T-02-05-06 | Denial of service | GitHub secondary rate limits | mitigate | RetryAfter helper; ETag 304 polling; serial dispatch queue in plan 02-11 |
| T-02-SC | Tampering | go get golang-jwt/jwt/v5 | mitigate | Approved in 02-01 with provenance evidence; exact version pin |
