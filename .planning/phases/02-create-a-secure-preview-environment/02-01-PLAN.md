## Phase Goal

**As an** SRE, **I want to** create a preview environment from a branch, PR or ref with one dashboard action, **so that** it comes up isolated, resource-limited and emitting telemetry, with the whole creation visible as one trace.

<objective>
Run the project's package legitimacy gate once for every new dependency in Phase 2 (RESEARCH "Package Legitimacy Audit"), so later plans reference this approval instead of re-asking. Collect provenance evidence, record exact pins with official checksums and digests in `deploy/kind/versions.env`, then stop for a blocking human approval. Nothing is installed in this plan.

Purpose: ASVS V14 / supply chain. The research flagged everything as NEW; the Helm checksum was never compared to the published `.sha256sum`.
Output: `deploy/kind/versions.env` and a recorded approval in the SUMMARY.
</objective>
